This directory contains the program to implement the algorithm of Kobayashi,
Komuro, and Tamaki in <https://doi.org/10.1007/978-3-319-07959-2_33>, written
by Yasuaki Kobayashi. The program computes optimal decompositions.

To run:

```bash
make build
java -cp .build/pathwidth.jar Pathwidth <.col path>
```
